Brief Guide: Modbus 4-20mA Distance Sensor

1. Key Technical Specifications

  • Measurement Range: 0.2…8 m (hardware blind zone is less than 200 mm).
  • Maximum Achievable Resolution: 1 mm (provided by built-in digital processing).
  • Power Supply Voltage: 8…28 V DC (VDC).
  • Power Consumption: Not exceeding 3 W.
  • Communication Interface: RS-485 (two-wire, half-duplex, default port settings: 9600 bps, 8N1).
  • Analog Output: Active 4–20 mA current loop (internally powered, 12-bit DAC, load resistance not exceeding 250 ohms).

2. Electrical Connection (Pinout and Wire Colors)

Wiring must be performed strictly while the power supply is switched off. For long communication lines, it is recommended to install a 120-ohm termination resistor at the ends of the RS-485 line.

3. Modbus Register Map (Holding Registers)

Data exchange is performed using standard Modbus RTU functions: 03h (read), 06h, and 10h (write). Parameter changes take effect immediately after writing.

2, 3MeasurementsRInt16 / UInt16Reg2: Internal temperature (°C, Signed Int16). Reg3: Calculated output current (Unsigned UInt16, ×100 mA).

16, 17Current RangeR/WUInt16Distance boundaries X1 for 4 mA (Reg16, default: 250) and X2 for 20 mA (Reg17, default: 5000).

4. Two-Point Calibration of the Measurement Tract

Calibration compensates for systematic errors in the measurement tract. It is recommended to choose calibration points that are as far apart as possible within your physical measurement zone.

  1. Point 1: Place a target in front of the sensor at a stable, known distance (e.g., 500 mm). Write this distance value: Reg14 = 500. Trigger the first capture by writing the command: Reg20 = 3.
  2. Point 2: Move the target to a second known distance (e.g., 5000 mm). Write this distance value: Reg15 = 5000. Trigger the second capture by writing the command: Reg20 = 4. The device will calculate the coefficients and save them to the non-volatile memory.
  3. Completion: Write the command Reg20 = 0 to the control register to return the device to normal operation mode.

5. 4-20 mA Analog Output Configuration and Calibration

  1. Scaling: Define the distance range corresponding to the minimum and maximum output current by configuring Reg16 (X1 — 4 mA distance) and Reg17 (X2 — 20 mA distance).
  2. Current Loop Calibration: Connect a milliammeter in series with the analog output. Ensure that the load resistance in the current loop does not exceed 250 ohms.
    • 4 mA Calibration: Write the command Reg20 = 1. Modify the value of register Reg18 until the milliammeter reads exactly 4.00 mA.
    • 20 mA Calibration: Write the command Reg20 = 2. Modify the value of register Reg19 until the milliammeter reads exactly 20.00 mA.
  3. Completion: Write the command Reg20 = 0 to save all settings to the non-volatile memory.

6. Installation and Operation Requirements

  • The sensor does not have to be installed strictly vertically. However, for maximum measurement accuracy, the laser beam must be perpendicular to the measured target surface.
  • Ensure there are no foreign objects in the beam path (such as tank walls, internal ladders, pipes, or floating debris).
  • Avoid condensation and dirt buildup on the optical window.
  • When operating the device outdoors, install a protective cover to shield the optical window from weather precipitation and direct sunlight.

7. Faults and Corrective Actions

Issue Possible Cause Corrective Action
No Modbus communication No power supply / Reversed A and B lines / Wrong address or port settings Verify power supply (8...28 V); swap the A and B communication wires; check or rewrite the address in Reg10; configure the Master device to 9600 bps, 8N1.
Register 0 is always 0 Target is in the blind zone (< 200 mm) / Weak signal (dirty optical window) Increase the distance to the target; gently clean the sensor window using a soft wipe.
Output is always 4 mA Distance is less than X1 / Device remained in calibration mode Check the values in Reg16 and Reg17; make sure Reg20 is set to 0.
Current does not match distance Incorrect range calibration or corrupt DAC values Reconfigure boundaries X1, X2 (Section 5, step 1) and calibrate the current output (Section 5, step 2).
